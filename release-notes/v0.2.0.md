# v0.2.0 — ストップウォッチ・レベルと称号・Web 版

ストップウォッチと、作業の時間で上がるレベル・称号を足しました。ブラウザーで使える Web 版も始めました。パソコン版（Windows）の配信はやめ、Android 版と Web 版の 2 つになりました。

**Android 版をお使いの方へ：この版は、今までのアプリとは別のアプリとして入ります。** 下の「Android 版を入れ替える」をご覧ください。

## 新しい機能
- **ストップウォッチ**：カードの左上のボタンで、タイマーとストップウォッチを切り替えられます。1 時間までは「分:秒」、1 時間からは「時:分:秒」で表示します。ストップウォッチで測った時間も、集中の記録に入ります。
- **レベル**：作業した時間 1 分で 1 xp がたまり、xp でレベルが上がります。Lv 1 までは 100 xp で、そこから 1 つ上がるごとに、必要な xp が 50 ずつ増えます。メイン画面の時間の上に、レベルと次のレベルまでの進み具合を表示します。xp はこの版から数え始めます（それまでの記録は xp に入りません）。
- **称号**：決まったレベルに届くと、称号がもらえます。Lv 1 の「はじめの一歩」から Lv 68 の「時の支配者」まで、13 個あります。

## Web 版
- <https://marusako.github.io/focusr/> を開くと、ブラウザーでそのまま使えます。インストールはいりません。
- データは、開いたブラウザーの中にだけ保存されます。設定の「一般」→「データ」の「書き出し」で、ファイルに持ち出せます。
- 通知は、設定の「一般」→「通知」で許可すると届きます（タブを開いている間だけ）。Android の Chrome では、今は通知が出ません。
- 外部カレンダーの取り込みは、Android 版だけで使えます。

## Android 版を入れ替える
名前を Focusr にそろえるため、アプリの識別子（Android がアプリを見分ける名前）を変えました。そのため、この版は今までのアプリの上からは入らず、別のアプリとして入ります。今までのアプリには、更新のお知らせも出ません。

1. **今までのアプリで、データを書き出します。** 設定の「一般」→「データ」の「書き出し」で、ファイルに保存します。
2. **この Release の `focusr-0.2.0.apk` を入れます。** Android のスマホのブラウザーでダウンロードし、ファイルを押して「インストール」を押します。「この提供元のアプリを許可」を求められたら、オンにします。Google Play で配っていないため、Google Play プロテクトの警告が出ることがあります。「詳細」→「インストールする」で入れられます。
3. **新しいアプリで、データを読み込みます。** 設定の「一般」→「データ」の「読み込み」で、1 で保存したファイルを選びます。設定・予定・時間割・集中の記録が戻ります。取り込んだ曲と壁紙は書き出しに入らないので、取り込み直してください。外部カレンダーも、登録し直してください。
4. **今までのアプリを消します。** 入れ替えている間は、ホーム画面に同じ「Focusr」が 2 つ並びます。新しいアプリでデータが戻ったことを確かめてから、古いほうを消してください。

次の版からは、この版の上から更新できます。

## パソコン版（Windows）
- 配信をやめました。今入っているパソコン版はそのまま使えますが、更新はもう届きません。代わりに Web 版をお使いください。パソコン版のデータは、パソコン版の「書き出し」で保存したファイルを、Web 版や Android 版の「読み込み」で戻せます。
