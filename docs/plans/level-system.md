# レベル制度（最初の版）

ROADMAP の「レベル制度と報酬」の ① を作る。称号・育成ゲーム・レベルアップの演出は、この版には入れない。

## 決めたこと（2026-10-31、開発者）
- 1 分 = 1xp。xp が入るのは「作業の時間」だけ（タイマーの作業・ラウンドのコマ・ストップウォッチ。休憩は入れない）
- 初期は Lv0。Lv0→1 に 100xp、そのあとは必要な xp が 50 ずつ増える（Lv1→2 は 150、Lv2→3 は 200…）
- 表示はメイン画面のカード
- 今までの集中の記録（過去 3 か月分）は xp に反映しない。今日から数える

## 受け入れ条件
1. 累計の作業時間（ミリ秒）から、xp（1 分 = 1xp、1 分に満たない端数は切り捨て）とレベルが決まる
2. 次のレベルに必要な xp は、Lv n → n+1 で `100 + 50 * n`。Lv n に着くのに要る累計の xp は `100 * n + 50 * n * (n - 1) / 2`（Lv1=100、Lv2=250、Lv3=450、Lv10=3,250、Lv30=24,750）
3. 作業の時間を足せる（足したあとは、上限以内の時間の合計になる）。1 回に足せる時間の上限は focus-log.js の `MAX_STEP_MS`（スリープ明けなどで、まとめて足さないため）。0 以下は何もしない
4. 1 分に満たない端数は捨てずに持ち越す（累計をミリ秒で持つ）。1 回に足せる上限があるので、たとえば 1 秒を 30 回足して 30 秒（0xp）、さらに 30 回足して 60 秒になると 1xp になる
5. 保存データ（data.json の `xp`）は、壊れていても起動できる。数値でない・負・無限大は 0 として読む
6. `xp` は保存する項目に入る（DATA_KEYS）。データの書き出し・読み込みにも含まれる
7. カードに「Lv N」と、次のレベルまでの進み具合を小さく出す。タイマーのモードにもストップウォッチの表示にも出る。作業の時間が足されると、表示が増える
8. 足す時間は、集中の記録に足す時間と同じもの（タイマー・ラウンド・ストップウォッチが重なって動いても、2 回数えない）
9. 全言語の翻訳がそろう（i18n のテストが通る）

## 外から見える形

### src/level.js（新規。画面にも Electron にも依存しない純粋な関数）
- `FIRST_LEVEL_XP = 100`、`LEVEL_STEP_XP = 50`、`MS_PER_XP = 60000`
- `createXp()` → `{ ms: 0 }`
- `addXpMs(xp, ms)` → 新しい `{ ms }`（元は書き換えない）。`ms` は `MAX_STEP_MS` で頭打ち。0 以下・数値でないときは元の `xp` をそのまま返す
- `totalXp(xp)` → 整数（`Math.floor(xp.ms / MS_PER_XP)`）
- `xpToReach(level)` → Lv `level` に着くのに要る累計の xp（`xpToReach(0) === 0`）
- `levelInfo(xp)` → `{ level, xp: 累計の xp, into: 今のレベルの中で進んだ xp, span: 今のレベルから次のレベルまでに要る xp, ratio: into / span (0 以上 1 未満) }`
- `parseXp(raw)` → 保存データから読んだ値を確かめて `{ ms }` にする。形が違う・`ms` が有限の 0 以上の数でないときは `createXp()`

### src/data-file.js
- `DATA_KEYS` に `'xp'` を最後に足す（`['settings', 'events', 'timetable', 'focusLog', 'xp']`）

### 画面（src/renderer.js・index.html・style.css・i18n.js と locales/）
- `let xp = parseXp(load('xp', null))`。`recordFocusTime` で足す `ms` と同じ値を `addXpMs` で足し、集中の記録と同じ保存のタイミング（`saveFocusLog`）で `save('xp', xp)` する
- カードに、`Lv N` の文字と、細い進みのバーを出す。文字は i18n の項目 `level`（`Lv {level}`、全言語で同じ形）
- 場所と見た目は、カードの左右の角のボタンや円の邪魔にならないところ（時計のあたり）。画面の拡大縮小に合わせるため、大きさは `calc(N * var(--u))` で書く

## 範囲に入れないもの
称号・育成ゲーム・レベルアップの通知や演出・過去の記録からの初期 xp・xp のリセットの操作
