# 称号（最初の版）

ROADMAP の「レベル制度と報酬」の ② を作る。育成ゲーム・称号の一覧画面・称号を得たときの通知や演出は、この版には入れない。

## 決めたこと（2026-11-02、開発者）
- 称号は「レベル」で決める。保存するものは増やさない（今のレベルから、いつでも計算できる）
- 段階は 13 個。Google Play の称号の時間の刻み（1・3・10・20・40・60・100・300・500・750・1,000・1,500・2,000 時間）を、今のレベルの式に当てはめた
- 見た目は、まず文字と色つきの図形で作る。あとで開発者が絵に差し替えられる作りにする
- 名前は、Google Play のものと重ならないオリジナル（下の表）

## 受け入れ条件
1. レベルから、今の称号が決まる。Lv0 はまだ称号がない（null）。表の「必要なレベル」以上で、いちばん高い段階の称号になる（Lv3 は t02、Lv4 は t03、Lv100 は t13）
2. 次の称号（まだ届いていない、いちばん低い段階）と、そこまでに足りないレベルが分かる。最高位に着いたら、次の称号はない（null）
3. 称号の表は、段階の順に並び、必要なレベルが小さい順で、重ならない
4. カードの「Lv N」のそばに、称号の名前と、色つきの図形（バッジ）を小さく出す。Lv0 は何も足さない
5. バッジの色は、段階が上がるにつれて青から紫へ変わる（13 段階が見分けられる）。絵に差し替えるときは、バッジの部品だけを入れ替えればよい作りにする
6. 称号の名前は、全言語の翻訳にそろえる（i18n のテストが通る）。名前は、項目 `title.<id>`（例: `title.t01`）にする
7. 称号が変わった瞬間の通知・演出は、この版では出さない

## 外から見える形

### src/titles.js（新規。画面にも Electron にも依存しない純粋な関数）
- `TITLES`: `[{ id: 't01', level: 1 }, ... { id: 't13', level: 68 }]`（凍結した配列。上の表の id と必要なレベル）
- `titleFor(level)` → 今の称号 `{ id, level, tier }`（`tier` は 0 から数えた段階の番号。t01 が 0、t13 が 12）。なければ `null`
- `nextTitle(level)` → 次の称号 `{ id, level, tier, remaining }`（`remaining` は、足りないレベル = その称号の `level - 今のレベル`）。最高位なら `null`

### 画面（src/renderer.js・index.html・style.css・i18n.js と locales/）
- `renderLevel()` の中で、`titleFor(info.level)` から称号の名前（`t('title.' + id)`）とバッジを出す。バッジの色は CSS の `data-tier`（0〜12）で決める
- 大きさは `calc(N * var(--u))`。カードの角のボタン・円の邪魔にならない場所

## 範囲に入れないもの
称号の一覧画面・称号を得たときの通知や演出・称号の絵・育成ゲーム
